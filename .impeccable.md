## Design Context

### Users
E-commerce managers and small business owners who manage product listings across Russian marketplaces (Ozon, Wildberries). They need an efficient, organized interface to handle catalog management, attribute mapping, and marketplace integrations. Their context is operational — they're working through product lists, editing details, and monitoring sync status. Speed and clarity are paramount.

### Brand Personality
**Professional, Organized, Trustworthy** — similar in spirit to Notion or Linear. The interface should feel competent and reliable, never flashy or playful. Users should feel confident that their data is correct and their actions are clear.

### Aesthetic Direction
- **Clean neutral** — maintain the current monochromatic shadcn/shadcn-vue "new-york" style with neutral grays and minimal color
- OKLCH color system with CSS custom properties for light/dark mode
- System font stack (system-ui, Avenir, Helvetica, Arial, sans-serif)
- Reka-UI primitives + shadcn-vue component patterns (Card, Table, Form, Dialog, Button)
- Lucide icons at 16px default size
- Border radius: 0.625rem (10px) default
- Spacing: Tailwind scale with adaptive padding system for responsive layouts
- Color is reserved for semantic meaning: destructive (red), warning (amber), success (green)
- Anti-references: avoid playful, colorful, or marketing-heavy aesthetics

### Design Principles
1. **Clarity over decoration** — Every element should serve a purpose. No ornamental UI. Use whitespace, typography weight, and layout hierarchy to communicate structure.
2. **Data density with breathing room** — Users work with product tables and forms all day. Show enough information to be efficient, but maintain comfortable spacing so the interface doesn't feel cramped.
3. **Consistent patterns** — Use the established component library (Card, Table, Form, Dialog) uniformly. Same spacing, same interaction patterns, same visual weight across all pages.
4. **Semantic color only** — Reserve color for status and actions (destructive, warning, success). The neutral palette keeps attention on content, not chrome.
5. **Accessible by default** — WCAG AA compliance: sufficient contrast ratios, visible focus states, proper ARIA attributes, keyboard navigation support throughout.

### Technical Constraints
- Vue 3 + Tailwind CSS 4 + Reka-UI (headless) + CVA for variants
- All UI text in Russian (no i18n library)
- Dark mode fully supported via `.dark` class + OKLCH variable swapping
- Component styling via `cn()` utility (clsx + tailwind-merge)
- Forms: Vee Validate + Zod schemas
- Toasts: vue-sonner
